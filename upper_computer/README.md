# ESP-WATCH 上位机（阶段 8）

这是 Qt 6 Widgets 上位机，包含 USB 配置入口、公共无线连接服务和演示遥控。专注任务页暂时保留为后续阶段入口。

## 构建

在 Qt Creator 中打开本目录的 `CMakeLists.txt`，选择 `Qt 6.11.2 MinGW 64-bit` 套件后构建运行。

## 首次连接

1. Windows 设置中开启“移动热点”。
2. 启动上位机，在“电脑当前 IPv4”中找出热点网卡地址；Windows 热点常见地址是 `192.168.137.1`，但应以上位机实际显示为准。
3. USB 连接手表，关闭 VS Code 串口监视器，在上位机选择手表串口并连接。
4. 填写热点名称、密码、电脑 IPv4、端口和配对令牌，点击“写入配置”，再点击“重启手表”。
5. 点击“启动无线服务”。首次出现 Windows 防火墙提示时允许“专用网络”。
6. 手表连上热点并完成认证后，上位机状态变为“手表已连接”。

密码、SESSDATA 和配对令牌不会由手表原文返回。读取配置后相应输入框留空表示保留设备中的旧值。

原 v1.1 上位机仍可用于 QR/封面图片传输；本阶段没有改变固件的图片串口协议。

## WPS 演示遥控

1. 先按上面的步骤让手表无线连接到上位机。
2. 手表进入“演示遥控”页面。
3. 在上位机“演示遥控”页勾选“启用演示控制”。
4. 用 WPS 打开放映文件并进入全屏放映；如果此前已经放映，请用 `Alt+Tab` 切回 WPS，使放映窗口保持在前台。
5. 手表上拨发送上一页，下拨发送下一页。拨轮每次按下只执行一次，按住不会连续翻页。
6. 拨轮短按只提示手势功能将在阶段 9 启用；长按退出演示遥控。

电脑端会检查前台进程是新版 WPS 统一进程（`wps.exe`）、旧版 WPS 演示（`wpp.exe`）或 PowerPoint（`powerpnt.exe`），并检查窗口覆盖当前显示器后才模拟 `Page Up` / `Page Down`。本机 WPS 12.1.0.28505 的演示入口实测指向 `wps.exe`。切到普通窗口或其他程序时会拒绝指令。电脑返回的“已处理”表示模拟按键已经发送，不代表程序读取到了真实页码。
